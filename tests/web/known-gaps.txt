# Cases where `lava run --surface=web` does not print what Chrome recorded.
#
#   <case> <stage>: <reason>
#
# The stage is the step of the Node-profile removal that closes the gap
# (tests/web/README.md lists them). Each listed case is held to its pinned Lava output
# in tests/web/known/<case>.lava, so a gap that changes is a failure too; one that
# starts matching Chrome fails until its line and pin are removed.
# `unplanned` marks a gap no removal stage closes: it needs an issue of its own.

robust-resizable-views unplanned: Chrome refuses a view over a resizable ArrayBuffer in every WebIDL byte argument (no [AllowResizable]); Lava reads the view's current bytes. Closes with WebIDL conversions (#12)
robust-view-probe unplanned: as robust-resizable-views: Chrome refuses the resizable-backed window, Lava decodes it as empty (it never reads the stale bytes this case guards against)
shape-crypto unplanned: no crypto.subtle (SubtleCrypto is not implemented); the Crypto interface and getRandomValues/randomUUID match Chrome (#114)
shape-events unplanned: EventTarget.prototype has no when() (Chrome 158's Observable API; there is no Observable global either); every other EventTarget, Event and CustomEvent member matches Chrome's shape and order
shape-fetch unplanned: Request.prototype and Response.prototype have no textStream() (Chrome 158's decoded-text body stream, not implemented); every other Headers, Request, Response and FormData member matches Chrome's shape and order (#114)
shape-missing unplanned: the Chrome globals of the shape-* families Larva does not implement (TextEncoderStream, FileReader, SubtleCrypto, reportError, …) — one line each, so implementing one is a visible change
shape-performance unplanned: Performance.prototype has no timing, navigation, memory or eventCounts (PerformanceTiming, PerformanceNavigation, MemoryInfo and EventCounts are not implemented); every other Performance, PerformanceEntry, PerformanceMark and PerformanceMeasure member matches Chrome's shape and order
storage-named-gaps unplanned: Storage's named properties are a Proxy, not V8 interceptors over a hash map: items enumerate in property order where Chrome uses its hash order; an item the prototype shadows is left out of Object.keys (Chrome lists it); a non-configurable data descriptor is refused (the Proxy invariant), where Chrome stores it; Reflect.defineProperty with an accessor answers false (WebIDL), where Chrome answers true
timers-string-handler unplanned: a non-function handler is ignored (no timer, the delay not converted) where Chrome converts it to a string and runs it as a script when the timer fires; needs a native that evaluates source in the page's global scope
url-host-space unplanned: Chrome percent-encodes a space in a special URL's host and accepts it; Lava follows the WHATWG parser and throws. Deciding whether to follow Chrome here is parser work, not message work
wasm-streaming unplanned: no WebAssembly.compileStreaming/instantiateStreaming (Blink's, over a Response; JSC GTK has none) — a fingerprint; not stubbed, since a stub that rejects breaks loaders that would take their ArrayBuffer path; the implementation over Response needs an issue of its own
xhr-sync unplanned: synchronous XMLHttpRequest (open(…, false)) is refused by send() with a NotSupportedError, where Chrome blocks the page until the response is in and fires the events from inside send(); needs send() to run the transport to completion on the page's thread (#13)
