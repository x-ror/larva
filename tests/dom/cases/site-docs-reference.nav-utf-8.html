Array.prototype.flatMap()

The flatMap() method returns a new array formed by applying a callback to each element, then flattening the result by one level.

Syntax

flatMap(callbackFn)
flatMap(callbackFn, thisArg)

Parameters

callbackFn

A function to execute for each element. It should return an array containing new elements, or a single non-array value.

thisArg Optional
A value to use as this when executing callbackFn.

Description

Note: flatMap is equivalent to map(...).flat() with depth 1.

Alternative

const arr = [1, 2];
arr.reduce((acc, x) => acc.concat([x, x * 2]), []);
// [1, 2, 2, 4]  (a < b && c)

Examples

InputOutput
[[1], [2]][1, 2]
["a b", "c"]["a", "b", "c"]

The formula is n≤m2 in the worst case.
